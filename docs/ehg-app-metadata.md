### Lighting — Standard Circuits (summary)

All standard `LightCircuit` components use 1–3 slots in the same pattern:

| Slots | Capabilities | Buses |
|-------|-------------|-------|
| 1 (On only) | `On` | 78, 94 |
| 2 (On + Brightness) | `On`, `Brightness` | 11, 13–14, 16–20, 22, 38–39, 43–44, 66–67, 80–86, 93, 113 |
| 3 (On + Brightness + Color) | `On`, `Brightness`, `Color` | 12, 15, 23, 40–42 |

Light groups (buses 24–27) always have 3 slots: `On`, `Brightness`, `NightMode`.
